# FApix Racing: реализация VV-136

Источник: https://linear.app/finext-io/issue/VV-136, живой дизайн https://fapixracing.com, приложенный скриншот. Пользователь уточнил: сайт — дизайнерский прототип, исходной рабочей игры нет. Создаём самостоятельный продукт в пустой папке car-game. Пользователь поручил автономно вести команду до результата.

## Подходы
Рассмотрены копирование готового bundle, 2D canvas и самостоятельная React/Three.js игра. Выбор команды: React + TypeScript + Three.js; bundle не даёт сопровождаемого продукта, 2D не соответствует видимой 3D игре. Node/SQLite для локального долговечного аккаунта и экономики; интеграция Arco Pay по соседним проектам. Этот выбор сделан командой в рамках делегированной автономии.

## Пользовательские сценарии
Лендинг с точной визуальной системой референса → тренировочная гонка без регистрации → 3 круга с 5 ботами → результаты → повтор/паддок. Паддок → выбор одного из 4 окружений → гараж → каталог минимум 300 товаров → покупка только при достаточном балансе → применение внешнего вида на трассе. Популярные товары 2×3 → сумма 311/584/1039/2077/2903/5205 ₽ → проверка логина → карта/СБП → подтверждённое зачисление → самостоятельная покупка внутри игры. Истории пополнений и покупок разделены.

Курс 1 ₽ = 2 Fapix. Минимальные новые товары: 10 машин, 20 цветов, 20 обвесов, 20 дисков, 10 помещений, 20 декоров, 20 шлемов, 20 комбинезонов. Остальной ассортимент: реальные поддержанные косметические категории и комплекты. Купленное нельзя купить повторно. Данные не являются только frontend localStorage.

## Качество и границы
Управляемая гонка, честный счёт кругов, пауза/возврат/результат, клавиатура и touch, responsive UI, доступные формы, ошибки/загрузка/пустые состояния. Изоляция реализации: новая папка, чужой код только читаем. Исследовательские скриншоты не обещают фотореалистичное 3D; игра использует low-poly модели как в референсе.

Живые платежи требуют выделенных merchant credentials и callback URL; чужие секреты не переносим. Без них показываем недоступность реального платежа и отдельный явный sandbox. Не заявляем production settlement без авторитетного статуса провайдера. Не размещаем платёжные данные карт в нашем приложении. Мультиплеер требует отдельной серверной симуляции, его обещание не подменяем ботами.
