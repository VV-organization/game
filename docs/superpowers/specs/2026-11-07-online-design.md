# Сетевая гонка FApix

Исходное поручение: исследовать аналоги и проект, реализовать настоящий онлайн; максимум 30 секунд подбора, затем заполнить свободные места ботами. Боты обозначаются компактной меткой AI, без выдачи за людей. Исследование: `docs/research/online-product-research.md`.

## Продуктовые решения

- Шесть мест; публичный подбор по трассе и соревновательному формату. Classic/sprint/elimination/endurance доступны онлайн; time-attack остаётся одиночной.
- Первый игрок задаёт неизменный deadline +30 секунд. Полная комната стартует сразу. По deadline свободные места занимает AI, затем общий отсчёт 3.6 секунды. 30 секунд — предел подбора, а не скрытое продление ожидания.
- Приглашение по коду ожидающей комнаты. Полная/начатая/несуществующая комната возвращает понятную ошибку. Один аккаунт/гостевой сеанс — одно место.
- Сервер принимает только ввод, reset и управление подключением. Имена, экипировка, физика, круги, бонусы и результат принадлежат серверу.
- Esc/скрытая вкладка сбрасывают ввод и открывают локальное меню; сервер не ставится на паузу. Отключившийся получает 12 секунд на возврат в своё место; затем DNF, без приписывания ему результата бота. Пустые места исходного подбора заполняются AI, отключённые не маскируются.
- Круговые гонки: до финиша всех либо 30 секунд после первого финиша; абсолютный предел 5 минут. DNF сортируется по подтверждённой дистанции. Выбывание заканчивается единственным активным участником. Выносливость — общий лимит 180 секунд.
- Повтор создаёт новый подбор с прежними настройками (не обещаем сохранение группы). История различает online/local и DNF. Платежи остаются disabled.

## Архитектура и альтернативы

Выбран `ws` на существующем Node HTTP-сервере и native WebSocket в браузере. Это позволяет переиспользовать чистую TypeScript-симуляцию без отдельного игрового фреймворка. Socket.IO/Colyseus дают дополнительные абстракции, но не заменяют серверную физику, валидацию и продуктовые правила восстановления. P2P/доверие координатам клиента не подходят для согласованных результатов.

Сервер: фиксированный шаг 60 Hz, снимки 20 Hz, ограниченный catch-up. Снимки не содержат геометрию трассы, деньги/инвентарь/секреты. Клиент сглаживает положение; окончательные результаты берёт только с сервера. Stable slot IDs не переставляются для локального игрока.

Протокол в `src/shared/online-protocol.ts`. Сессия/гостевая cookie проверяется при upgrade, Origin разрешается только для приложения; resume-токен привязан к actor/room/slot и обновляется. Ограничены payload, частота сообщений, соединения, комнаты и буфер отправки. Штатное завершение закрывает сокеты и таймеры.

## Границы готовности

Обязательны тесты с несколькими реальными WebSocket-клиентами, проверка двух браузеров с независимыми сессиями, 30-секундное заполнение AI, общие результаты и восстановление. Публичное размещение требует адреса/сервера; вопрос пользователю отправлен, локальная работа не заблокирована. Отдельно отмечать локально проверенный онлайн и публичный доступ. Без рейтинговых выплат, чата и покупки сетевой инфраструктуры.
